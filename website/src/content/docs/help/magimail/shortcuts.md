Magimail supports native macOS application shortcuts alongside standard Gmail web shortcuts.

## Window & Account Navigation

| Action                | Shortcut                      | Notes                                                    |
| :-------------------- | :---------------------------- | :------------------------------------------------------- |
| Switch to Account 1–9 | <kbd>⌘1</kbd> – <kbd>⌘9</kbd> | Instantly switches active account tab.                   |
| Back in history       | <kbd>⌘[</kbd>                 | Also supports two-finger swipe left and mouse button 4.  |
| Forward in history    | <kbd>⌘]</kbd>                 | Also supports two-finger swipe right and mouse button 5. |
| Reload mailbox        | <kbd>⌘R</kbd>                 | Reloads the current account's web session.               |
| Find in page          | <kbd>⌘F</kbd>                 | Searches the text of the page you are reading.           |
| Search mailbox        | <kbd>⌥⌘F</kbd>                | Jumps directly to Gmail's server search input.           |
| Find Next             | <kbd>⌘G</kbd>                 | Advances to the next search match.                       |
| Find Previous         | <kbd>⇧⌘G</kbd>                | Moves to the previous search match.                      |
| Settings              | <kbd>⌘,</kbd>                 | Opens the settings window.                               |
| Close window          | <kbd>⌘W</kbd>                 | Closes detached thread or compose window.                |
| Quit Magimail         | <kbd>⌘Q</kbd>                 | Quits Magimail.                                          |

Switching accounts, and what each one keeps separate, is in [Multiple Accounts](/help/magimail/accounts/).

## Composing Messages

| Action                      | Shortcut           | Description                                                                                                   |
| :-------------------------- | :----------------- | :------------------------------------------------------------------------------------------------------------ |
| New Message                 | <kbd>⌘N</kbd>      | Opens a standard compose draft in the active account.                                                         |
| New Detached Compose Window | <kbd>⇧⌘N</kbd>     | Opens an independent, floating compose window with native macOS window controls.                              |
| Global Quick Compose        | <kbd>⌥⌘C</kbd>     | Opens a compose window from any app. See [Quick Compose](/help/magimail/quick-compose/).                      |
| Detached Thread Window      | <kbd>⇧</kbd>+Click | Hold <kbd>Shift</kbd> while clicking any email thread in your message list to pop it out into its own window. |
| Send Message                | <kbd>⌘Enter</kbd>  | Sends the draft currently in focus.                                                                           |

## Gmail In-Mail Shortcuts

Magimail preserves Gmail's built-in single-key shortcuts when enabled in Gmail settings:

| Action           | Shortcut                     | Description                                   |
| :--------------- | :--------------------------- | :-------------------------------------------- |
| Compose          | <kbd>C</kbd>                 | Create a new email within the current window. |
| Search mail      | <kbd>/</kbd>                 | Focus Gmail search query field.               |
| Archive          | <kbd>E</kbd> or <kbd>Y</kbd> | Archive selected conversation.                |
| Delete message   | <kbd>#</kbd>                 | Move selected message to Trash.               |
| Mark as unread   | <kbd>⇧U</kbd>                | Mark conversation as unread.                  |
| Mark as read     | <kbd>⇧I</kbd>                | Mark conversation as read.                    |
| Star message     | <kbd>S</kbd>                 | Toggle star status.                           |
| Reply            | <kbd>R</kbd>                 | Reply to active message.                      |
| Reply all        | <kbd>A</kbd>                 | Reply to all recipients on thread.            |
| Forward          | <kbd>F</kbd>                 | Forward message.                              |
| Select thread    | <kbd>X</kbd>                 | Select or deselect conversation checkbox.     |
| Next message     | <kbd>J</kbd>                 | Navigate down to older conversation.          |
| Previous message | <kbd>K</kbd>                 | Navigate up to newer conversation.            |
