---
title: Google Tasks
description: How Magical shows Google Tasks beside your meetings, and how completing, adding and deleting one reaches Google.
---

A task with a date belongs to the day it is due, so Magical draws it in the same agenda as your meetings instead of leaving it in a panel you have to go and open.

## Where Tasks Appear

- **[Menu bar popover](/help/magical/menu-bar/)**: a task sits in its day, labelled with the calendar it belongs to. One with only a due date reads **All day**; one you have dragged onto a time in Google Calendar appears at that time.
- **[Desktop widgets](/help/magical/widgets/)**: the same agenda, on the desktop. A completed task is greyed out here too, and **Settings → Appearance → Show completed tasks** decides whether it is drawn at all. See [Settings Reference](/help/magical/settings/).
- **Main window**: Google Calendar's own Tasks panel. **Settings → Appearance → Hide Tasks tab** hides it, which leaves the popover and the widgets as the places a task shows up. See [Settings Reference](/help/magical/settings/).

## Completing a Task

Right-click a task in the [popover](/help/magical/menu-bar/) and choose **Mark Complete**. The row greys out and stops counting as something to do, and the tick is written to Google Tasks, so the same task is finished on your phone and in a browser.

Choose **Mark Incomplete** on a completed task to reopen it.

Magical applies the tick immediately and then reads Google back, so a slow round trip does not leave the row looking untouched. A completed task never raises an alert, however its due time falls.

## Adding a Task

The toolbar's <span class="sym sym-circle-badge-plus" aria-hidden="true"></span> **New Task** button opens Google Calendar's own new-task field, in the account the window is showing. The task is created by Calendar rather than by a copy of it, so it lands in the list Google shows on every device.

See [Window Toolbar](/help/magical/toolbar/) for adding the button, or moving it.

## Deleting a Task

Right-click a task and choose **Delete Task**, in the [popover](/help/magical/menu-bar/). A native confirmation appears first, and the task is deleted in Google Tasks.

## Recurring Tasks

A repeating task shows each occurrence separately, so ticking off today's does not tick next week's. Each one is a task of its own in Google Tasks too.

## Hiding Completed Tasks

**Settings → Appearance → Show completed tasks** is on by default, which keeps completed tasks in place and greyed out. See [Settings Reference](/help/magical/settings/). Turning it off leaves only the work that is still outstanding in the popover and the widgets.
