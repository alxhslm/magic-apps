Magical provides native macOS application shortcuts, date browsing gestures and Google Calendar keys for moving around your schedule.

## Window & Calendar Navigation

| Action                 | Shortcut / Gesture                               | Notes                                                           |
| :--------------------- | :----------------------------------------------- | :-------------------------------------------------------------- |
| Switch to Account 1–9  | <kbd>⌘1</kbd> – <kbd>⌘9</kbd>                    | Instantly selects account tab in the window toolbar.            |
| Jump to Today          | <kbd>T</kbd>                                     | Centres the view on today.                                      |
| Previous Period        | <kbd>K</kbd> or <kbd>P</kbd>                     | Shift to previous day, week, or month.                          |
| Next Period            | <kbd>J</kbd> or <kbd>N</kbd>                     | Shift to next day, week, or month.                              |
| Back in History        | <kbd>⌘[</kbd> or Mouse Back Button (Button 4)    | Steps back out of search, event editors, or deep-linked dates.  |
| Forward in History     | <kbd>⌘]</kbd> or Mouse Forward Button (Button 5) | Moves forward along your navigation trail.                      |
| Swipe Dates (Trackpad) | Two-Finger Swipe Left / Right                    | Fluid horizontal swipe shifts previous or next calendar period. |
| Tilt Wheel (Mouse)     | Horizontal Wheel Notch                           | Shifts previous or next calendar period.                        |
| Reload Calendar        | <kbd>⌘R</kbd> or <kbd>R</kbd>                    | Refreshes active Google Calendar web view.                      |
| Search Events          | <kbd>/</kbd> or <kbd>⌥⌘F</kbd>                   | Opens Google Calendar's search results for the active account.  |
| Settings               | <kbd>⌘,</kbd>                                    | Opens the settings window.                                      |
| Close Window           | <kbd>⌘W</kbd>                                    | Hides window (Magical keeps running in your menu bar).          |
| Quit Magical           | <kbd>⌘Q</kbd>                                    | Quits Magical completely.                                       |

The toolbar's own search field, and the mouse and trackpad navigation in full, are in [Window Toolbar](/help/magical/toolbar/).

## Calendar View Modes

| View Mode              | Shortcut                     | Description                                         |
| :--------------------- | :--------------------------- | :-------------------------------------------------- |
| Day View               | <kbd>1</kbd> or <kbd>D</kbd> | Displays a single day column with hourly grid.      |
| Week View              | <kbd>2</kbd> or <kbd>W</kbd> | Displays 7-day schedule view.                       |
| Month View             | <kbd>3</kbd> or <kbd>M</kbd> | Displays full monthly grid with event density dots. |
| Custom / 4-Day View    | <kbd>4</kbd> or <kbd>X</kbd> | Displays your configured rolling custom view.       |
| Agenda / Schedule View | <kbd>5</kbd> or <kbd>A</kbd> | Continuous chronological list of upcoming meetings. |
| Year View              | <kbd>6</kbd> or <kbd>Y</kbd> | Compact 12-month bird's-eye view.                   |

## Event & Task Management

A task is completed and deleted through controls of its own, which [Google Tasks](/help/magical/tasks/) covers.

| Action                | Shortcut                                  | Description                                                       |
| :-------------------- | :---------------------------------------- | :---------------------------------------------------------------- |
| Create Event          | <kbd>⌘N</kbd> or <kbd>C</kbd>             | Opens the event creation modal.                                   |
| Import Calendar File… | <kbd>⇧⌘I</kbd>                            | Opens file picker to import `.ics` / iCalendar files.             |
| View Event Details    | <kbd>E</kbd>                              | Opens details card for the currently selected meeting.            |
| Delete Event          | <kbd>Backspace</kbd> or <kbd>Delete</kbd> | Removes the selected event, or the occurrence of a recurring one. |
