Welcome to the help for Magimail and Magical. These pages explain how each app works, how to configure multiple accounts, the available keyboard shortcuts, and how each native macOS integration operates.

## Apps

Magic Apps brings Google Workspace into native macOS applications:

- **[Magimail](/help/magimail/getting-started/)**: A native macOS client for Gmail. Combines full Gmail capability (schedule send, snooze, server search) with native toolbars, separate sessions per account, menu bar unread previews, desktop widgets, the system Share Sheet, deep links and Focus Filters.
- **[Magical](/help/magical/getting-started/)**: A native macOS client for Google Calendar. Provides multi-account calendar views, meeting countdown in the menu bar, direct video call joining, interactive desktop widgets, an Invitation Tray for instant RSVPs, deep links, and Focus Filters.

## Core Principles

Both apps adhere to three shared foundations:

1. **Direct and local-first**: The apps communicate directly with Google's servers using your existing Google session. There are no intermediate proxy servers, no third-party account registration, and zero analytics or tracking telemetry.
2. **True session isolation**: Each added account runs in its own session. Cookies and credentials never cross between accounts.
3. **Deep macOS integration**: Rather than standard web wrappers, the apps provide native toolbars, system Share extensions, desktop widgets and notification actions that behave like built-in macOS software.
