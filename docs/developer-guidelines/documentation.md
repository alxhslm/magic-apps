# Documentation

The documentation lives in `docs/`, in Markdown, and GitHub renders it. Relative links between
documents resolve as written.

## Writing a document

Write plain Markdown. A new `docs/<app>/<name>.md` sits in the folder it belongs to, and that
folder's `README.md` indexes it. What belongs in a document is settled by
[`../README.md`](../README.md) and the `writing-docs` skill.
